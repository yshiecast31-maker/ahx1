ahx1

Zero-password AEAD transport · root entropy only

Authenticated encryption with no user passphrase. The only secret is a 256-bit root intended to live in a TPM, Secure Enclave, or equivalent hardware keystore.

Properties

  • ChaCha20-Poly1305 AEAD
  • Dual independent HKDF expansions
  • SHA3-HMAC header integrity (checked first)
  • Pre-mix under a third derived key
  • Opaque marker ahx1:
  • Generic failure messages only
